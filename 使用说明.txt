=======================================================
   Windicator+ (Windows 11 虚拟桌面指示器增强版)
=======================================================

【项目简介】
Windicator+ 是一款轻量、绿色免安装的 Windows 11 虚拟桌面任务栏与桌面指示器工具。
基于开源项目 Wielding/Windicator 进行演进与深度重构，采用 MIT 开源协议发布。

【核心交互与操作说明】
1. 托盘图标交互：
   - 鼠标单击（左键或右键）：在任务栏上方精确唤起控制菜单。
   - 鼠标双击：快速打开偏好设置中心（Settings）。
2. 桌面悬浮指示器（Watermark Overlay）：
   - 日常鼠标完全穿透（Desktop Clickthrough）：采用 Win32 分层窗口技术，平时不阻挡底层应用的任何点击与拖拽操作。
   - 修饰键拖拽定位（Modifier Drag）：按住键盘修饰键（默认 Ctrl，可在设置中改为 Alt 或 Shift）同时按住鼠标左键即可拖动指示器到任意位置，松开后自动记忆坐标并恢复完全穿透。
3. 任务栏停靠与自适应：
   - 任务栏点击菜单（Taskbar Click）：当指示器贴靠在任务栏时，单击指示器可直接呼出控制菜单。
   - 空间不足浮动退让：动态监测任务栏可用空间；当运行程序过多导致任务栏拥挤时，指示器自动切换为浮动退让状态，杜绝与系统托盘及任务栏图标重叠。
   - 菜单 Z 序 200ms 条件检查：后台内置 200ms 周期条件探活，维持 [菜单] > [指示器] > [任务栏着色] > [Shell任务栏] 的层级关系，防止菜单被任务栏遮挡。
4. 个性化配置：
   - 每桌面自定义颜色：支持为不同虚拟桌面单独配置专属任务栏强调色（Taskbar Tint）与主题外观。
   - 桌面别名重命名：支持为每个虚拟桌面设定自定义名称（如“主屏开发”、“日常办公”），并在指示器与托盘悬停提示中实时显示。

【技术边界与客观说明】
1. 非零 CPU 承诺：以系统注册表通知为主实现事件驱动监听，常态空闲低开销，但包含必要的界面绘制、层级协调与空间监测逻辑，运行时存在微量 CPU 消耗，不虚构“0% CPU”或“秒开神话”。
2. Primary-only Tint：任务栏色彩叠加仅作用于主显示器任务栏，多显示器副屏维持原生外观。
3. 不保留 Shell 空间：软件以顶层分层窗口贴合任务栏，不向系统注册占用任务栏 AppBar 物理保留区，不改变 Windows 原生布局。
4. 截图工具说明：置顶悬浮指示器属于分层窗口，在使用全屏截图或部分截图工具时可能会被捕获进画面中，不保证零瞬时遮挡。
5. 配置与自启动：
   - 配置文件持久化保存在：%APPDATA%\WindicatorPlus\config.ini。
   - 开机自启动为完全可选功能，通过注册表当前用户项 HKCU\Software\Microsoft\Windows\CurrentVersion\Run 管理，可随时启闭。

【获取与安装】
- 预留发布入口：https://github.com/koxircom/WindicatorPlus/releases/latest （注：尚未正式创建 GitHub Release，该链接为预留入口）。
- 直接下载：公开源码根目录中已提供预编译好的免安装程序 WindicatorPlus.exe，单文件下载即用。
- 本地编译：基于 Windows 11 自带 .NET Framework 内置编译器（csc.exe），双击 build.bat 即可完成本地零外部依赖构建。
- 退出与卸载：在托盘或控制菜单点击“退出”即可完全关闭；如需彻底移除，删除本程序文件以及 %APPDATA%\WindicatorPlus 目录即可，零残留。
