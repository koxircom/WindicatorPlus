# WindicatorPlus / IndepenDesk bridge v1

Scope: IndepenDesk alone owns independent window sets, switching and recovery. Windicator consumer is read-only. Existing Windows native mode is untouched by default. No automatic engine install/start/registry changes. Standalone portable engine launched explicitly with `--windicator-bridge` disables StartupManager.ApplyOnLaunch and built-in OSD; normal engine launch unchanged.

Upstream IndepenDesk: 0.4.0, commit 21c9b74020898d96d77495aa9beec74e3c4d376b, MIT.

Transport: Windows named pipe, byte mode, outbound server only, PipeOptions.Asynchronous | PipeOptions.CurrentUserOnly, name `WindicatorPlus.IndepenDesk.v1.<current Windows SID>.<Process.GetCurrentProcess().SessionId>`. No TCP/listening external network, no request commands and no window-title/handle transmission. Server writes ONE UTF8 XML line then disconnects; consumer reconnects every 600ms, background worker only. Connect <=200ms, bounded read <=600ms and <=32768 bytes. Client closes connection on timeout. Server cancels during Dispose. No network or hidden-window journal polling.

Wire XML (single line):
`<state version="1" pid="123" session="1" instance="guid" sequence="1"><monitor device="\\.\DISPLAY1" ordinal="1" index="0" count="2" global="1" /></state>`
sequence strictly increments on EVERY UI-thread snapshot refresh, not only switching. Cache initial only after manager.Sync, refresh after DesktopSwitched AND each 600ms sync even during overview (snapshot read-only, no Sync during overview). GetCurrentInfos does NOT call Sync. Full snapshots include all monitors, so adding/pruning desktops on one screen refreshes other screen global ordinals. Server sends cached immutable snapshot; does not touch manager off UI thread. Final stop cancels server, consumer freshness expires.

Consumer: DTD/XmlResolver prohibited; document bound32KiB; version==1, valid instance GUID, pid>0 and session==current; <=32 unique devices (case insensitive), ordinal unique positive <=32, index0..8/count1..9 with index<count, global positive <=288. Reject entire malformed snapshot, unknown actual displays ignored (never fallback to primary). No window enumeration guesses. Repeated same instance/sequence does NOT refresh freshness; lower/equal revision rejected, new instance accepted. Monotonic Stopwatch freshness3seconds; stale/disconnect removes badges, never substitutes native number. On reconnect valid fresh snapshot recovers. Empty monitor list clears. Read-only PID check optional but cannot imply authentication; CurrentUserOnly and user/session-scoped name are boundary, not protection from another process of SAME user.

UI: each state device exact match to Screen.DeviceName; each count>=2 gets a nonactivating always-click-through per-monitor corner badge showing local desktop index+1 and monitor ordinal/current-count, not global-index alias. Global exposed separately. Per monitor+local-index names/colors stored separately from native aliases (defaults can use existing palette). Geometry pure tested using physical working area with negative origins, mixed scale96/144/192 DPI; margin22 DIP, size210x72 DIP or larger for text, fully within work area. Disconnected monitors removed, single-desktop hidden. No per-screen taskbar tint in this version (existing taskbar monitor is primary-only); use badge accent instead, do not pretend secondary taskbar validated. Settings/window activation only explicit menu actions; background updates never show settings or steal focus.

Acceptance: tests isolated Windows desktop isolated Windows desktop only only; protocol/geometry pure tests can be console with no UI. Never run engine on default user desktop during tests. No SwitchDesktop/SendInput; manager hides only generated test windows, no real config/hidden.json writes (test injection path). Product binaries versioned, native compatibility exe not deployed/replaced. No GitHub publication.
